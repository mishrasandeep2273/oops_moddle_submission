# Hostel Management System

## Overview
This repository contains two Java-based projects developed as part of the Object-Oriented Programming (OOP) course.

The projects demonstrate the implementation of Java programming concepts, database connectivity, and hostel management operations.

## Projects

### 1. HostelManagementAPI
A hostel management project developed using API-based architecture.

**Key Concepts:**
- Object-Oriented Programming
- API Development
- Database Integration
- CRUD Operations

### 2. HostelManagementJDBC
A hostel management project using Java Database Connectivity (JDBC) to interact with a database.

**Key Concepts:**
- Java Database Connectivity (JDBC)
- SQL Queries
- CRUD Operations
- Database Management
- OOP Concepts
